# UI 2.0

## Start

An empty page with the buttons provided in the screenshot:

- New: Opens modal with folder selection, etc.
- Dropdown: Select already ingested folders and opens modal
- Run: Run randomizer based in settings
- Reset: Reset Dropdown selection and randomizer

## Modal with Options

- Option to change / select folder
- Search option
- Option to select all or deselect all entries
- Entry selection
- Mode
- Results (is only available, when "Pick" is selected)
- Save to save and make it available for selection in dropdown
